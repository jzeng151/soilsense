# Chat research citations

Both Sprout web chat and the ConversationRelay phone agent expose `search_research({ question, crops? })`. It calls the existing `researchFor` boundary, searches all supported tags when crops are omitted, preserves verbatim text and public source metadata, and returns at most `MAX_PASSAGES`. It never substitutes a saved plan-comparison bundle for an arbitrary chat question. A saved result returned by the retrieval boundary would retain its saved status; unavailable/empty results have no passages and an explicit reason. Retrieval is bounded to 12 seconds.

## Runtime enforcement

- A server-owned registry assigns short IDs (`R1`, `R2`, …) to returned chunk IDs, reusing an ID for repeat searches in that registry. Web registries are **per turn**: search again when referring to research in a later reply. Client-supplied historical tool results are not admitted as verified citations. Phone registries last for the call.
- At web stream finish, all `[R<number>]` markers are checked. Unknown IDs produce a visible warning and a structured log. Only valid cited passages produce research source links and expandable verbatim quotes with title/year/publisher/applicability. Sources generated by the model itself are not forwarded. Dataset links from trusted tools remain unchanged.
- On the phone, complete model text blocks are buffered before speech. This handles IDs split across model stream tokens. Valid markers become spoken publisher, year and source title; invalid markers become an explicit unverified-source message and are logged. The research tool uses the existing timed voice-event logger.
- Consented plan SMS messages append deduplicated URLs for passages cited before the send tool executes. The complete message is capped at 1,600 characters: preserve complete links, trim plan prose if needed, and explicitly disclose excess omitted links. Sources cited after an already-sent SMS are not retroactively sent.
- Settings automatically lists the enabled-by-default tool through `VOICE_TOOLS`; its description is editable and stale stored settings receive the new default.

## Instructions, not semantic proof

The prompts (including phone `LOCKED_RULES`) require research claims to use returned evidence and inline IDs; data-tool numbers must name their dataset; unsupported claims must be acknowledged as unknown. **The runtime checks citation identity, not sentence-level entailment or every factual claim.** A model can still omit a citation, misuse a valid passage, or invent an uncited fact. Dataset attribution and numerical grounding remain instructions, not a numeric/semantic verifier. Do not describe this as a guarantee that every generated statement is true or fully cited.
